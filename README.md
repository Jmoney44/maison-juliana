# Maison Juliana

Luxury in Every Scent.

- `website/` – landing page (`index.html`) with WhatsApp ordering. Add product photos to `website/images/` (see the README there).
- `brand-kit.html` / `Maison-Juliana-Brand-Kit.pdf` – brand identity guidelines.
- `logos/` – logo files (PNG, transparent and solid backgrounds).
- `landing-page.html` – source of the landing page as published on Claude.

To host for free: enable GitHub Pages (Settings → Pages → branch `main`, folder `/website` is not supported directly, so use root or move `website/index.html` to the root), or drag the `website` folder onto app.netlify.com/drop.
