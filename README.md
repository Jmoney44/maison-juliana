# Maison Juliana

Luxury in Every Scent.

- `docs/` – the live website (`index.html`) with WhatsApp ordering, served by GitHub Pages at https://jmoney44.github.io/maison-juliana/. Add product photos to `docs/images/` (see the README there).
- `brand-kit.html` / `Maison-Juliana-Brand-Kit.pdf` – brand identity guidelines.
- `logos/` – logo files (PNG, transparent and solid backgrounds).
- `landing-page.html` – source of the landing page as published on Claude.

Hosting: GitHub Pages serves the `docs/` folder from the `main` branch. Any change pushed to `docs/` goes live within a minute or two.
